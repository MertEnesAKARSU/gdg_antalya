# 🚀 GDG Antalya - Build with AI 2026

I always believe in the power of continuous learning and staying connected with technology communities. This repository contains the materials, codes, and my personal experience from the **"Build with AI"** workshop organized by [GDG Antalya](https://gdg.community.dev/gdg-antalya/).

## 🗓️ Event Details
* **Event:** GDG Antalya - Build with AI
* **Date:** May 9, 2026
* **Location:** Antalya, Turkey
* **Focus:** Artificial Intelligence, LLMs, and practical AI integration in modern software architecture.

## 💡 Workshop Highlights
Rather than just exploring AI theory, this event provided a hands-on workshop experience. We implemented current AI technologies into real-world project scenarios. This practical approach reinforced my vision that AI is not just a simple tool, but a core component that elevates software architectures to the next level.

*(Note: The codebase in this repository includes the workshop practices, including the `bean-house` project implementations.)*
